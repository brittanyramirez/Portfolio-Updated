Sweet Cravings

A responsive bakery website focused on modern layouts, data driven content, and advanced CSS techniques.

View Code Live Demo

Project Overview

Sweet Cravings is a front end focused project built to demonstrate advanced CSS layouts, responsive design, and dynamic content rendering using JavaScript and JSON. The goal was to create a visually engaging bakery website that feels modern, clean, and user friendly across devices.
During development, I applied techniques learned from the Advanced CSS and Sass: Flexbox, Grid, Animations and More! course by Jonas Schmedtmann, including complex CSS Grid layouts, responsive breakpoints, Sass architecture, and hover animations. This project strengthened my understanding of scalable CSS structure, layout problem solving, and building visually polished interfaces that adapt smoothly across screen sizes.

Tech Stack

  • HTML5 (Semantic Structure)
  • CSS / SCSS (Grid, Flexbox, Collage Layouts)
  • JavaScript (DOM Manipulation, Fetch API)
  • JSON (Dynamic product data)
  • Responsive Design (Mobile → Desktop)

Key Features

Dynamic Cake Menu

Cake items are rendered dynamically from a JSON file using JavaScript.

Advanced CSS Layouts

Custom grid based collage gallery with varied image sizing.

Fully Responsive

Optimized layouts for mobile, tablet, and desktop breakpoints.

Modern UI Design

Soft color palette, clean typography, and interactive hover states.

Challenges & Growth

One of the biggest challenges in this project was managing complex CSS Grid layouts while maintaining responsiveness across breakpoints. Through trial, debugging, and iteration, I strengthened my understanding of layout flow, grid positioning, and responsive design strategies.
