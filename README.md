## 🍰 Featured Project: Sweet Cravings

**Sweet Cravings** is a frontend focused project built to demonstrate:

- Advanced CSS layouts
- Responsive design techniques
- Dynamic content rendering with JavaScript and JSON

### What I focused on:
- CSS Grid & Flexbox for complex layouts
- Sass architecture with partials and variables
- Image collage layouts
- Responsive breakpoints
- Fetching and rendering data from a JSON file

## 📱 Responsive Design

This portfolio is fully responsive with **three main breakpoints**:

- **Mobile:** ≤ 768px
- **Tablet:** 769px – 1024px
- **Desktop:** ≥ 1025px

Layouts adapt using flexible grids, stacked navigation, and scalable typography to ensure a smooth experience across devices.
